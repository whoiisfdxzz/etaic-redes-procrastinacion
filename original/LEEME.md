# Archivo recibido

`script_etaic_definitivo_recibido.py` es el script tal como se recibió, sin cambios. Lee el Excel con una función que no está en Python estándar, así que no se ejecuta fuera del entorno donde se escribió. La versión que se ejecuta es `../script_etaic_definitivo.py`, que cambia solo la lectura del Excel a openpyxl y añade exportaciones. La huella SHA-256 de los dos archivos está en `../procedencia.json`.
